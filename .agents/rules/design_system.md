# Web Design Excellence & Component Standards

Always apply high-craft UI/UX engineering inspired by **Unlumen UI**, **Magic UI Pro**, **Smooth UI**, and **Neobrutalism**. 

### 1. Magic UI Pro (Landing Pages & Modern SaaS)
- **Bento Grids**: Varied spanning cards with live interactive mini-previews, badges, and contextual visual hierarchy.
- **Dynamic Borders**: Border Beam (traveling gradient strokes), Shine Border, Spotlight card tracking.
- **Kinetic Elements**: Seamless continuous marquees, interactive floating docks, animated text scrambles/word flippers, meteors & retro grids.

### 2. Unlumen UI (Luxury Dark Tech & Glow)
- **Cinematic Depth**: Obsidian/deep slate surfaces (`#080808`, `#0b0c10`), multi-layered radial glow gradients, subtle noise grain.
- **Refined Glassmorphism**: `backdrop-blur-xl bg-white/[0.03]` with micro-borders (`border border-white/10`).
- **Polished Typography**: Tight tracking for bold headings, spaced uppercase tracking for tags, crisp neutral-400 subtext.

### 3. Smooth UI (Physics & Micro-Interactions)
- **Spring Physics**: Smooth damping/stiffness curve over linear CSS easing.
- **Fluid Layouts**: Sliding tab pills (`layoutId`), dynamic expanding accordions/modals without jarring layout jumps.
- **Tactile Feedback**: Active push states (`active:scale-[0.98]`), magnetic hover pulls, 3D cursor-reactive card tilts.

### 4. Neobrutalism (High-Contrast & Chunky Playful)
- **Hard Shadows & Thick Strokes**: 2px-3px solid dark borders (`border-2 border-black`), offset solid drop shadows (`shadow-[4px_4px_0px_0px_#000]`).
- **Tactile Translate States**: Buttons that depress physically on click (`hover:translate-x-[-2px] hover:translate-y-[-2px]`, `active:translate-x-[2px] active:translate-y-[2px]`).
- **Vibrant Color Blocking**: Acid lime, electric lavender, bright pastel accents with black typography & retro sticker badges.

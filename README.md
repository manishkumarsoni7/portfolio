# Manish Kumar Soni — Flagship Web Designer & AI Portfolio

An **Awwwards-caliber, high-craft editorial portfolio** for **Manish Kumar Soni**, Lead Web Designer, Creative Technologist, and Autonomous AI Engineer.

Built with an **Obsidian Luxury Aesthetic (`#050608` / `#00f2fe`)**, fluid rem-based viewport grid architecture, Lenis smooth inertia scrolling, spring kinetic reveals, and interactive flagship project showcases.

---

## 🌟 Key Architectural Features

- **Cascade Rolling Typography:** Interactive letter-by-letter kinetic rolling text reveals on display headings.
- **Connoisseur Works Showcase:** Interactive SVG-clipped project showcase featuring 4 real-world production platforms (*AURA Spatial Atelier, Apex Nova Dental, Chronos Haute Horlogerie, Autonomous AI Swarms*).
- **Monolith Editorial Accordion (2.1):** High-density technical stack and skills explorer.
- **Adaptive Viewport Grid:** Fluid root-rem architecture providing identical optical balance from 320px mobile to 4K ultra-wide screens.
- **B&W to Real-Color Hover Interactions:** Spring physics photo plates with dynamic color transitions on hover.
- **Sub-500ms Edge Performance:** Pure vanilla ESM architecture with zero bloated framework overhead.

## 🛠️ Local Development

Clone the repository and run the local development server:

```bash
# Clone the repository
git clone https://github.com/manishkumarsoni7/portfolio.git

# Navigate into the project
cd portfolio

# Run the local server
node server.js
```

Open `http://localhost:3000` in your browser.
